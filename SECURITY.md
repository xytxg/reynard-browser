# Security Policy

Reynard Browser is experimental and this Chinese localization fork is maintained independently. The existence of CI checks, static analysis or Codex-assisted review **does not imply a security audit, certification, or absence of vulnerabilities**.

## Supported versions

This fork focuses on its latest source snapshot. Older archived CI artifacts, unsigned builds, and unsupported installation methods do not receive guaranteed security updates.

## Reporting vulnerabilities

**Do not publish proof-of-concept exploits, sensitive tokens or user data in a public issue or pull request.** Use GitHub's **Report a vulnerability** private reporting option if it is enabled for this repository. If unavailable, contact the maintainer via the GitHub profile to agree on a private disclosure channel before sharing technical details.

Please include affected commit, device/iOS version, installation method, impact, reproducible steps, and whether the issue is already present in upstream. Security problems in unchanged upstream code may also need coordinated reporting to [the upstream project](https://github.com/minh-ton/reynard-browser).

There is no promised response time or bug bounty. Confirmed fixes should receive focused code review, test coverage where feasible, and an attributable public change after appropriate disclosure.
